# 斗地主终极版

一个网页版斗地主游戏，支持 AI 对战、用户系统、战绩记录与回放。

## 项目起源

家里长辈退休后想玩斗地主，但市面上的 App 广告多、需要充值，操作也不方便。
于是做了这个**免费、无广告、打开网页就能玩**的版本，后来逐步迭代加上了 AI 策略、用户系统和部署上线。

## 在线体验

已部署到腾讯云 CloudBase，电脑和手机浏览器可直接访问。

## 功能特性

- **AI 对战**：三个 AI 对手，具备记牌、拆牌判断、手数分析与概率推算能力，非随机出牌
- **用户系统**：注册登录、战绩统计（胜场、胜率、最高连胜）
- **战绩回放**：保存并回看历史牌局，支持复盘
- **排行榜**：多用户战绩排行
- **响应式布局**：适配电脑端与手机端

## 技术栈

**后端**
- Python 3 + Flask
- MySQL（生产，腾讯云 CynosDB）／ SQLite（本地开发降级）
- RESTful API 设计

**前端**
- HTML / CSS / JavaScript（原生，无框架）
- 前后端分离，通过 API 交互

**部署**
- 腾讯云 CloudBase
- GitHub Actions 自动部署
- Docker 支持

## 项目结构

```
├── backend/
│   ├── app.py          # Flask 主程序：路由、用户、战绩、排行榜
│   ├── ai_engine.py    # AI 出牌引擎：牌型识别、手数分析、策略评估
│   ├── ai_state.py     # 牌局状态管理
│   └── database/       # 本地 SQLite 数据库（不入库）
├── frontend/
│   ├── index.html      # 游戏主页面
│   ├── lobby.html      # 大厅：登录、排行榜、回放入口
│   ├── game.js         # 游戏交互逻辑
│   └── style.css       # 样式
├── audio/              # 音效资源
└── tests/              # 测试脚本
```

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 启动后端
cd backend
python app.py

# 浏览器访问
http://localhost:8080
```

> 后端默认监听 8080 端口。数据库不可用时会自动降级到本地 SQLite，不影响游戏运行。

## AI 策略说明

AI 采用启发式搜索，核心逻辑包括：

1. **手数分析**：估算出完剩余手牌所需的回合数
2. **拆牌罚分层级**：评估拆牌代价，避免破坏关键牌型
3. **概率记牌推算**：根据已出牌与剩余牌数估算位置概率（不读取暗手，仅基于公开信息，保证公平）
4. **让牌三原则**：从位置、牌型、代价三个维度判断是否让牌

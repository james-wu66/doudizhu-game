如何刷新真实数据

双击运行工作台根目录下的 刷新工作台.bat，它会调用 引擎/生成控制台.py 重新扫描真实项目、重新生成本页面与 项目状态.json。 刷新后按 F5 重载本页面即可看到最新真实数据。

终端命令：cd "斗地主最终版工作台" && python 引擎/生成控制台.py

说明：本控制台是"生成时刻的快照"。你本地重跑生成器才会更新；推到 GitHub 的那份别人看到的是冻结快照，碰不到你机器上的项目数据。

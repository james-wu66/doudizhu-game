## 🚀 快速开始

### 第一步：打开控制台
浏览器打开 `控制台.html`（或在本目录起本地服务后访问）

### 第二步：安装依赖（可选，跑测试时才需要）
```bash
cd "C:\hermes 斗地主终极版 软件\斗地主最终版工作台\配置"
npm install
```

### 第三步：运行测试
```bash
# 运行前端测试
npm run test:frontend

# 运行后端测试
npm run test:backend

# 运行所有测试
npm test
```

### 第四步：推进任务
1. 查看 `任务看板/当前任务.md` 了解任务详情与进度
2. TASK-001 手数分析：提示词已就绪在 `提示词/TASK-001-手数分析.md`
3. 用户明确说"你现在改/你来改/去改"后，代码执行者按提示词实现
4. 测试验证者按提示词中的 13 条验收用例（C1–C13）逐项验证

## 📋 使用指南

### 提示词工程师
1. 阅读`协作流程/角色职责.md`了解职责
2. 查看`任务看板/当前任务.md`获取任务
3. 撰写提示词文档，准备验收清单
4. 使用保险库管理知识和决策

### 代码执行者
1. 等待用户明确说"你现在改/你来改/去改"
2. 接收提示词文档，分析影响范围
3. 执行代码修改，每修改一个点立即测试
4. 生成执行日志，记录修改内容

### 测试验证者
1. 配置测试环境（运行`npm install`）
2. 设计测试用例，编写测试脚本
3. 运行测试，生成测试报告
4. 发现问题，返回给提示词工程师
